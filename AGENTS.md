## Default workflows and knowledge

Use the `deko-implement` skill for features, bug fixes, refactoring and performance work, and the
`deko-pr` skill for PRs. `knowledge/` is an OKF bundle: start at
[knowledge/index.md](knowledge/index.md) and follow the `okf` skill when editing it. Confirm claims
against current source.

If these skills are not installed, install them with `npx skills add Dekoruma/f1-ai -g`, then start a
new session.
